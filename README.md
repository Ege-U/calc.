# calc. - The Calculator Better Than Yours
"calc." is a calculator I made to be better than the defalt calculator app on your PC.
It has a lot of features, maybe even too much.
You can choose out of 26 themes and you can make your own custom ones!
"calc." is currently available as a ".py" file and a ".html" file.
# Dependencies
"calc.py" requires "matplotlib" & "numpy" to work
# calc-zero
"calc-zero" just has no dependencies.
"calc-zero" is only available as a ".py" file.
